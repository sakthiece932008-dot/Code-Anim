# Code Anim

Upload or paste code, press **Visualize**, and watch it run step by step: the left window highlights the current line, the right window animates variables, arrays, trees, linked lists, console output and (for GUI/applet/HTML code) a drawn screen.

## Run it in Chrome
Recommended: `node server.js`, then open http://localhost:3000 in Chrome. (You can also open `public/index.html` directly or with VS Code Live Server; click **🔑 API key** and paste your key to visualize non-JavaScript languages.)

## Run in VS Code
1. Install Node.js 18+ (and Python 3 for real Python tracing).
2. Open this folder in VS Code, open a terminal.
3. Copy `.env.example` to `.env` and put your OpenAI (or Anthropic) API key in it.
4. `node server.js` (or press F5), then open http://localhost:3000

## How each language runs
- JavaScript / Node.js (plain logic): executed for real in the browser.
- Python: executed for real by `tracers/py_tracer.py` on your machine (10 s limit; your code runs locally).
- Java, C, C++, Kotlin, React, HTML, Android and others: the server asks Claude to simulate the run step by step (needs the API key).

## Beginner mode
Every step shows a plain-English explanation with everyday analogies (labelled boxes, recipes, yes/no questions) plus what just changed. For Java/C/C++/etc. the AI writes these explanations itself.

## Layout
`server.js` (static server + /api/trace), `tracers/py_tracer.py`, `public/` (index.html, style.css, app.js).
